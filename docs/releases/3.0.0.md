# CodexWeb Council 3.0.0

CodexWeb Council 3.0.0 is the Electron-first multi-ChatGPT collaboration release.

## Highlights

- Persistent normal ChatGPT conversations bound to stable managed agent identities.
- Playwright resume, wake and resurrection transport without tab-title or coordinate guessing.
- Controller-owned ACLs shared by MCP and browser action paths.
- Lead/Chair can create specialist ChatGPT agents with bounded delegated permissions.
- Council rooms, proposals, threaded critique, tasks, reviews, checkpoints and final decisions.
- Final decision gate requires a proposal and, for multi-agent rooms, independent peer participation.
- Up to five active Electron ChatGPT browser surfaces; additional agents can sleep/queue and later resume their saved conversation.
- Plus fallback can bind the currently open persistent ChatGPT conversation as Lead without exposing owner-control credentials to the renderer.
- Existing Secure MCP Tunnel path and ChatGPT login flow are preserved.
- Additive Agents and Council UI; existing launcher shell remains intact.
- Update now / Later / Skip-this-version flow, with release downloads pinned to `Nolane-x/codexweb` and SHA-256 verification.

## Release assets

The GitHub Release workflow builds and smoke-tests native Electron distributions on:

- Windows x64 (`.exe`)
- Linux x64 (`.AppImage`)
- macOS Apple Silicon (`.dmg` + `.zip`)
- macOS Intel (`.dmg` + `.zip`)

It also publishes standalone runtime archives, install scripts, license notices, demo media and `checksums.txt` covering every release asset.

## Security

Council 3.0 hardens model identity spoofing, permission delegation, privileged MCP/browser parity, unmanaged-participant privilege bypass, private checkpoint/token leakage, wake storms, duplicate resurrection after ambiguous network failures, half-applied action batches, owner-control redirects, renderer authority and final-policy shortcuts.

See `docs/security-council-3.0.md` for the detailed threat/security review.
