# CodexWeb Council 3.1.0

Council 3.1.0 is the standalone-product correction release after the 3.0 migration.

## Fixed

- Removed active Council setup dependency on Codex integration state.
- Council/Tunnel setup no longer reads, restores, or mutates `~/.codex/config.toml`, `openai_base_url`, Codex model catalog state, or the Codex integration journal.
- Replaced the packaged Electron entrypoint with a standalone Council bootstrap instead of loading the retired Codex launcher main.
- Council runtime supervision starts only the Secure MCP Tunnel; it does not start the retired Responses daemon.
- Added safe migration of already-saved codexweb Tunnel credentials without touching Codex configuration.
- Wired the Plus/no-MCP-write path end-to-end: persistent Project conversation → owner-authenticated local control → Lead binding → Playwright wake/agent runtime.
- Added strict Electron IPC so renderer code cannot provide the Lead URL, owner capability, role, id, or permissions.
- Added owner HTTP bearer authentication, rejection of all browser Origins, payload bounds, atomic capability descriptor writes, redirect rejection, and an 8-second request deadline.
- Added a standalone Council renderer with ChatGPT, Activity, Settings, Agents, Council, Connect, and update surfaces and no Codex setup/model-routing workflow.
- Changed the terminal runtime installer so it no longer launches a Codex setup command.
- Added CI concurrency cancellation so superseded verification runs do not block native runners.

## Compatibility

The connector identity remains `CodexWeb Council` to avoid forcing another ChatGPT connector-cache migration. The existing Electron application identity/artifact naming is also retained so 3.0 installations can update in place.

## Verification gate

A 3.1 release is permitted only after the release SHA passes:

- root version/audit/typecheck/test/build/smoke gates;
- active Council launcher tests;
- Windows Electron package + packaged smoke;
- Linux Electron package + packaged smoke;
- macOS Electron package + packaged smoke;
- release workflow native macOS ARM64 and Intel signature checks;
- checksummed GitHub Release asset publication.
